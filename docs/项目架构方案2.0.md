# 每日膳食搭配助手Agent - 项目架构方案2.0

> **面向求职简历优化版**：采用 LangChain + Redis + Streamlit 技术栈，快速落地可演示的 AI 应用。
> 
> 核心原则：**快速可演示、面试有亮点、技术栈主流**

## 一、技术栈选型对比

| 组件 | 1.0方案 | 2.0方案 | 变更理由 |
|------|---------|---------|---------|
| Agent框架 | LangGraph | **LangChain (LCEL)** | LangChain 社区更大、学习资料更多，LCEL链式调用更简洁，满足求职需求 |
| 前端框架 | Vue3 + Element Plus | **Streamlit** | 零前端代码，纯Python即可构建精美交互界面，1天可完成演示版 |
| 缓存/记忆 | Redis（辅助） | **Redis（核心）** | 对话记忆缓存、会话状态管理 |
| 向量库 | Chroma/Milvus | **Chroma** | 开发端用Chroma即可，生产端预留Milvus接口 |
| 数据库 | SQLite/PostgreSQL | **SQLite** | 开发端用SQLite，生产端预留PostgreSQL接口 |

### 3.2 LangChain Agent 核心设计

#### 3.2.1 LCEL 链式调用

使用 LangChain Expression Language（LCEL）实现膳食搭配 Agent 的多步骤处理流程：

```python
# backend/app/agent/chain.py

from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

class DietAgentChain:
    """膳食搭配Agent - LCEL链式调用实现"""
    
    def __init__(self, llm, retriever, tools):
        self.llm = llm
        self.retriever = retriever
        self.tools = tools
        self._build_chains()
    
    def _build_chains(self):
        """构建各阶段处理链"""
        
        # Chain 1: 信息收集与分析
        self.info_chain = (
            ChatPromptTemplate.from_template(INFO_PROMPT)
            | self.llm
            | StrOutputParser()
        )
        
        # Chain 2: 知识检索增强生成
        self.rag_chain = (
            {"context": self.retriever, "question": RunnablePassthrough()}
            | ChatPromptTemplate.from_template(RAG_PROMPT)
            | self.llm
            | StrOutputParser()
        )
        
        # Chain 3: 约束校验
        self.validate_chain = (
            ChatPromptTemplate.from_template(VALIDATE_PROMPT)
            | self.llm
            | StrOutputParser()
        )
        
        # Chain 4: 食谱生成（核心）
        self.generate_chain = (
            ChatPromptTemplate.from_template(GENERATE_PROMPT)
            | self.llm
            | StrOutputParser()
        )
    
    async def process(self, user_query: str, user_profile: dict) -> dict:
        """
        执行完整的膳食搭配流程
        
        流程：信息分析 → 知识检索 → 约束校验 → 食谱生成 → 结果输出
        """
        # Step 1: 分析用户需求
        info_result = await self.info_chain.ainvoke({
            "query": user_query,
            "profile": str(user_profile)
        })
        
        # Step 2: 检索相关知识
        retrieved_docs = await self.retriever.ainvoke(user_query)
        
        # Step 3: 约束校验
        validation = await self.validate_chain.ainvoke({
            "profile": str(user_profile),
            "docs": retrieved_docs
        })
        
        # Step 4: 生成食谱
        diet_plan = await self.generate_chain.ainvoke({
            "query": user_query,
            "profile": str(user_profile),
            "context": retrieved_docs,
            "validation": validation
        })
        
        return {
            "diet_plan": diet_plan,
            "retrieved_knowledge": retrieved_docs,
            "validation_result": validation
        }
```

#### 3.2.2 对话记忆管理（Redis）

```python
# backend/app/agent/memory.py

import redis
import json
from datetime import datetime, timedelta

class ConversationMemory:
    """基于Redis的对话记忆管理"""
    
    def __init__(self, redis_url="redis://localhost:6379/0"):
        self.redis_client = redis.from_url(redis_url)
        self.session_ttl = timedelta(hours=24)  # 会话保留24小时
    
    def add_message(self, session_id: str, role: str, content: str):
        """添加消息到会话历史"""
        key = f"session:{session_id}:messages"
        message = {
            "role": role,
            "content": content,
            "timestamp": datetime.now().isoformat()
        }
        self.redis_client.lpush(key, json.dumps(message))
        self.redis_client.expire(key, self.session_ttl)
    
    def get_history(self, session_id: str, max_turns: int = 10) -> list:
        """获取会话历史（最近N轮）"""
        key = f"session:{session_id}:messages"
        raw_messages = self.redis_client.lrange(key, 0, max_turns * 2)
        return [json.loads(msg) for msg in reversed(raw_messages)]
    
    def get_user_preferences(self, user_id: str) -> dict:
        """获取用户长期偏好"""
        key = f"user:{user_id}:preferences"
        prefs = self.redis_client.get(key)
        return json.loads(prefs) if prefs else {}
    
    def save_user_preferences(self, user_id: str, preferences: dict):
        """保存用户偏好"""
        key = f"user:{user_id}:preferences"
        self.redis_client.set(key, json.dumps(preferences))
        self.redis_client.expire(key, timedelta(days=30))
```

def render_diet_plan(diet_plan: dict):
